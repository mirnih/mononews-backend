# Mononews

Веб-приложение для публикации новостей о музыкальной индустрии, исполнителях и музыкальных лейблах. Реализованы серверная часть на NestJS, пользовательский интерфейс с серверной шаблонизацией, API и система аутентификации и авторизации.

## Стек технологий

- **TypeScript, Node.js, NestJS** — серверная часть приложения
- **PostgreSQL, TypeORM** — хранение данных и работа с БД
- **Handlebars (HBS)** — серверная шаблонизация страниц
- **REST API, Swagger/OpenAPI** — API и его документация
- **GraphQL, Apollo Server** — альтернативный интерфейс получения данных
- **Server-Sent Events (SSE)** — передача событий клиенту в реальном времени
- **SuperTokens** — аутентификация и управление пользовательскими сессиями
- **S3** — хранение изображений
- **Render** — развёртывание приложения

## Функциональность

- Управление статьями, музыкальными исполнителями, лейблами и связанными данными.
- Отображение страниц с использованием Handlebars и интеграцией шаблонов с серверной бизнес-логикой.
- Реализация RESTful API для работы с сущностями приложения и документация API через Swagger.
- Реализация GraphQL-схемы для получения и изменения данных.
- Использование возможностей NestJS для реализации Backend for Frontend (BFF).
- Передача обновлений клиенту с помощью Server-Sent Events.
- Регистрация, вход и выход пользователей, управление сессиями.
- Авторизация и разграничение доступа на основе ролей пользователей.
- Загрузка и хранение изображений в S3-совместимом объектном хранилище.
- Развёртывание серверного приложения и PostgreSQL на Render.

## Локальный запуск

Для запуска необходимы Node.js 22+, PostgreSQL и настроенные переменные окружения для подключения к базе данных, аутентификации и объектному хранилищу.

```bash
git clone https://github.com/mirnih/mononews-backend.git
cd mononews-backend
npm install
```

Применение миграций БД:

```bash
npm run migration:run
```

Запуск приложения в режиме разработки:

```bash
npm run start:dev
```

Сборка и запуск:

```bash
npm run build
npm run start:prod
```

## Доменная область

### **Mononews** - это информационная платформа посвященная музыкальной индустрии. Она позволяет публиковать материалы об исполнителях и группах, музыкальных лейблах, событиях и других новостях в сфере музыки.

## Сущности доменной модели

"User" - пользователь платформы, включает в себя: имя, адрес эл. почты, роль пользователя, дата создания и дата последнего изменения.

"Article" - новостная публикация, основные атрибуты: заголовок, уникальный адрес публикации, тип статьи, краткое описание, содержимое, дата публикации, создания и последнего изменения. Каждая статья имеет одного автора, который является пользователем платформы.

"Artist" - музыкальный исполнитель или группа. Сценическое имя, музыкальный жанр, страна, дата создания записи и последнего изменения.

Исполнитель может быть связан с нескольими статьями и ожет принадлежать музыкальному лейблу.

"MusicLabel" - музыкальный лейбл. Он включает в себя название музыкального лейбла, страну, описание, дату создания и последнего изменения.

"LabelStat" - показатели музыкального лейбла за определенный год, которая состоит из самого года, дохода, доли рынка и даты создания записи.

"Feedback" - отзывы пользователей о работе платформы. Основные атрибуты: текст сообщения, оценка и дата создания отзыва.

## Связи между сущностями

"User" - "Article" = один пользоваель - несколько статей  
"User" - "Feedback" = один пользователь - несколько отзывов  
"Artist" - "Article" = один исполнитель - несколько статей посвящено  
"MusicLabel" - "Artist" = один муз. лейбл - несколько исполнителей  
"MusicLabel" - "LabelStat" = один муз. лейбл = несколько стат. записей за разные года
